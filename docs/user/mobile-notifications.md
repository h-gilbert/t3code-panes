# iPhone notifications

The private iPhone app sends a completion notification when a turn submitted from
the iOS app finishes. This includes follow-up messages in existing threads and
messages queued on the phone. Starting a thread on the phone does not enable
completion alerts for later turns submitted from web or desktop.

Approval requests, requests for input, and failures still send alerts regardless
of where the turn started. Live Activities and Dynamic Island integration remain
disabled.

Both the iPhone app and its connected environment must support these completion
alerts. Until an environment is updated, completion alerts remain off there.
Open the updated app and connect to the environment to register its notification
preferences. Allow notifications in iOS Settings.
